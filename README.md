# 💼 InternHub – Internship Portal

## Overview

InternHub is a web-based internship portal developed using HTML and CSS. The project provides a simple platform where students can explore internship opportunities and submit applications through an online interface.

## Project Structure

```text
demo-main/
│
├── index.html
├── dockerfile
└── .github/
    └── workflows/
        └── docker-image.yml
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/internhub.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

* HTML5
* CSS3
